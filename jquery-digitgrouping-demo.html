jQuery Digit Grouping Plugin Demo

Set up in JavaScript:

Raw value: ""

Markup / Code:
<input id="amount"
       type="text"
       placeholder="1,234,567,890" />

$("#amount")
    .digitGrouping({
        separator: ",",
        groupSize: 3,
        maxDigits: 10
    });

Raw value: ""

Markup:
<input type='text'
       placeholder='0000 0000 0000 0000'
       data-digit-grouping=''
       data-group-size='4'
       data-separator=' '
       data-max-digits='16' />
